# Vibe-Coding Journal

Automated daily intelligence digest for vibe-coders — people building
software with AI coding tools (Bolt, Lovable, Replit, Cursor,
Windsurf, Claude Code, GitHub Copilot, v0, and similar).

Governed by [Commander](https://github.com/IDSS123a/commander) v1.2
(IDSS123a Organisation).

## Before doing anything in this repo

Read, in order:

1. `CLAUDE.md` — governance entry point, tells you what to read next
2. `CONSTITUTION.md` — project-specific rules (inherits Commander)
3. `sprints/SPRINT_01.md` — current sprint scope

Any AI Coding Assistant (Claude, Cursor, Windsurf, etc.) picking up
this repo should read these three files completely before writing
any code. No other context is needed — see Commander M-14, "GitHub
is the Runtime."
